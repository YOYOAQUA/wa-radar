# 📡 WA Radar: Claude קורא לכם את הוואטסאפ

**כמה כסף שוכב לכם בוואטסאפ?** לקוחות שביקשו הצעת מחיר ולא קיבלו תשובה. "אשלח לך מחר" שנשכח.
קבוצות שבהן מבקשים בדיוק את מה שאתם עושים, ואתם לא כותבים שם אף פעם.

הסקיל הזה הופך את Claude למנהל לשכה אישי, שעובר על כל הוואטסאפ ומחזיר לכם לוח אחד:
- ⏳ **מי מחכה לתשובה ממכם**, לפי דחיפות
- 💰 **לידים שלא חזרתם אליהם**
- 🤝 **הבטחות שנתתם** ולא קיימתם
- ✅ **רשימת משימות** מתוך השיחות
- 📣 **בקשות בקבוצות** שמתאימות בדיוק למה שאתם מוכרים
- 🚀 **הזדמנויות עסקיות** ו-💡 **רעיונות לפרויקטים** מתוך מה שאנשים שואלים שוב ושוב
- 🔥 **קשרים שהתקררו** ושווה לחמם

ליד כל פריט יש טיוטת תשובה בסגנון שלכם, וכפתור שפותח את וואטסאפ עם ההודעה מוכנה. **אתם לוחצים שלח.**
ויש גם תדריך בוקר שמחכה לכם כל יום, ותמלול של ההקלטות הקוליות.

## בטוח? כן, וזה החלק החשוב
- **קריאה בלבד.** Claude עובד על **עותק** של ההודעות במחשב שלכם. הוואטסאפ עצמו לא משתנה.
- **לא שולח כלום.** אין לו דרך לשלוח הודעה בשמכם. כל תשובה היא טיוטה.
- **בלי חיבור חיצוני.** לא מחברים את החשבון לשום שירות, אז אין סיכון לחסימה.
- **שיחות נעולות לא נקראות.**
- **חשוב לדעת:** כמו בכל שיחה עם Claude, מה שהוא קורא נשלח אליו לניתוח. ההודעות לא מועלות לשום מקום אחר.
- רוצים להסיר? מוחקים את התיקייה `WaRadar`.

## מה צריך
- אפליקציית **Claude** לדסקטופ, עם מנוי בתשלום (Pro ומעלה). עובדים בלשונית **Code**. להורדה: [claude.ai/download](https://claude.ai/download)
- **המסלול המלא: Mac** עם אפליקציית **WhatsApp למחשב** ([whatsapp.com/download](https://www.whatsapp.com/download)), מחוברת לטלפון.
- **המסלול המקוצר: Windows** (או בלי וואטסאפ למחשב). מייצאים מהטלפון 5-10 שיחות חשובות, ו-Claude מנתח אותן.

## התקנה (פעם אחת, כ-5 דקות)

**1. מתקינים את הסקיל.** פותחים את Claude ← לשונית Code ← סשן חדש, ומדביקים:

```
תתקין לי את הסקיל wa-radar מהקישור הזה:
https://github.com/YOYOAQUA/wa-radar
תוריד את הקבצים, תשים אותם בתיקיית הסקילים של Claude, ותבדוק שיש בתיקייה קובץ SKILL.md.
בסוף תגיד לי לפתוח סשן חדש.
```

**2. מתקינים את הרדאר.** פותחים **סשן חדש** וכותבים:

```
תתקין לי את הרדאר
```

אם המק שואל אם לאפשר ל-Claude גישה לנתונים של אפליקציות אחרות, לוחצים **אפשר**.

## איך עובדים
| כותבים ל-Claude | מה קורה |
|---|---|
| *"תריץ לי את הרדאר"* | סריקה מלאה, ולוח עם כל מה שפספסתם וטיוטות מוכנות |
| *"מי מחכה לתשובה ממני?"* | רק השיחות הפתוחות, לפי דחיפות |
| *"מה סיכמתי עם דנה?"* | סיכום של שיחה אחת, עם תאריכים |
| *"מה ביקשו ממני בקבוצת ההורים השבוע?"* | משימות מתוך קבוצה |
| *"תעשה לי תדריך בוקר כל יום ב-8"* | משימה קבועה שמכינה לכם לוח כל בוקר |
| *"גם ההקלטות"* | תמלול ההודעות הקוליות בעברית, על המחשב שלכם |

**המדריך המלא, עם צילומי מסך, בונה פרומפטים אישי וכל הפרומפטים עם כפתור העתקה:** [yoavyosha.ravpage.co.il/whatsapp](https://yoavyosha.ravpage.co.il/whatsapp)

## שאלות נפוצות
- **כמה זה עולה?** הסקיל חינמי. צריך מנוי Claude בתשלום.
- **יחסמו לי את הוואטסאפ?** לא. אין שום חיבור לחשבון. Claude קורא קובץ שכבר נמצא במחשב שלכם.
- **כמה היסטוריה הוא רואה?** את מה שיש בוואטסאפ למחשב. אם חיברתם אותו לאחרונה, שיחות ישנות אפשר לייצא מהטלפון.
- **משהו לא עובד?** כתבו ל-Claude: *"הרדאר לא עובד, תריץ בדיקה ותתקן"*.
